# spoti

A native Spotify Premium client in Odin, with SDL3 and Clay. Library
browsing, artwork, queues, seeking, encrypted audio caching, and native
Spotify Connect. Linux, macOS, and Windows; native Wayland on Linux.

```sh
just build    # build/spoti
just run
just test
```
